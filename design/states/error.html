Design notes

  1. Fail closed, and say so. A failed balance check stops the recompute: a figure that is a day old is better than a figure that is wrong. The banner leads with what you are looking at, then why.
  2. The old number stays, clearly labelled. The hero still shows a number, because a blank would be worse, but its as-of line turns amber and names the day.
  3. The error is written for a person, then for the ledger. First the likely cause in plain words; then the exact account, file and line, so the fix takes a minute.
  4. The next action is the specific one. "Find the $100.00" opens the transactions around that date, filtered to amounts near the difference.
  5. Errors respect privacy too. The details name an account and its balance, so only its owner sees them. Everyone else gets one sentence that reveals nothing.
