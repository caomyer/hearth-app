Design notes

  1. The same page, a different viewer. Sam shares categories with Alex; Alex shares categories with Sam; Jordan shares nothing. The question Sam asks is built from the same lists; what comes back is decided part by part.
  2. Nothing is refused; everything degrades to the grain it may have. A refusal ("too few transactions to show") would itself be an answer about the data. Instead each part enters at the finest grain its owner shares, which depends only on sharing choices, so the shape of the page says nothing the sharing page does not.
  3. A member who shares nothing is named once and counted nowhere. "without Jordan" on every total, the same words whether Jordan spent a lot or nothing.
  4. The who list names every member, because membership is already on Household. Choosing Jordan returns one sentence.
