Design notes

  1. The page lists what is withheld by name. "What Sam shares" uses the exact words of Sam's own sharing settings, so both people talk about the same six things.
  2. One private block, not four empty panels. Repeating a locked panel for every missing section reads as a wall. One block says what is private, why, and what would change it.
  3. No fake blurred data. The approved mock blurred placeholder rows. That suggests the data is present and merely obscured, which is the opposite of how the server enforces privacy. This page says plainly that the data was never sent.
  4. Violet hatch means "withheld by its owner". It is not red, because nothing is wrong, and not grey, because grey already means "not there yet". The same hatch appears wherever private data would otherwise be, including inside household charts.
  5. The admin is told that admin does not help. Decision 7 says no override. Saying so on the page heads off the obvious question.
  6. Joint accounts are fully visible. Decision 4: both owners see joint detail. The Joint tag says why this section is different from the rest of Sam's page. Joint is drawn in neutral grey everywhere: it belongs to no one member.
  7. The transfer reads from both sides. Alex's "Transfer to joint checking" (−460.00) arrives here as "Transfer from Alex" (+460.00), so the two pages reconcile.
